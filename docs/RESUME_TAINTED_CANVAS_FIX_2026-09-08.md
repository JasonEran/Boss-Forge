# 单候选人精筛反复异常：跨域画布截图修复

日期：2026-09-08。最终版本：`boss-canvas-fix-20260908-1045cst`。

## 线上问题

亚马逊运营任务 `2de28e4c-4e18-4724-8a96-e253218172ca` 本次上限 20 人，实际采集 16 人。15 人已完成，崔子静（状态 `a128c491-1973-4037-821c-8718d8169eaf`）失败。

- 09:47、09:57、10:07 的三次自动处理，以及 10:08 的人工重试，均显示 `BOSS_RESUME_CONTENT_EMPTY`，约 6 秒即失败，未进入规则核验。
- 临时诊断保留底层异常后，通过普通 Worker 的单次重试复现 `SecurityError: Failed to execute 'toDataURL' on 'HTMLCanvasElement': Tainted canvases may not be exported.`。临时诊断已撤回。
- 根因是原生画布截图直接调用 `canvas.toDataURL()`；该简历使用含跨域图像的画布，浏览器禁止导出其像素。外层截图代码又吞掉异常、返回 false，导致 UI 错报“内容未稳定加载”，进而安排无效重试。

## 修改

- 原生虚拟画布统一通过浏览器实际显示区域截图，不再直接导出画布像素，不修改浏览器跨域策略。
- 保持原始视口和折叠展开状态，滚动真实父容器；逐层核对嵌套 iframe、滚动容器和视口裁剪，确认段落连续、布局和像素稳定后保存。
- 生产复验发现 BOSS 推荐页 BODY 的 overflow 实际传播到视口；按 CSS 视口规则计算裁剪，避免把已滚动的 BODY 边界误认为可见区域。新增与生产一致的固定高度、已滚动 BODY 夹具。
- 补齐 `content_incomplete` 的服务端手动重试许可，修复前端显示可重试而后端拒绝的遗漏，继续保留候选人身份变化和风控的既有处理。
- 截图坐标支持小数 CSS 位置与高倍像素密度；生成整数分段元数据，并通过现有严格完整性读取器验证。
- 移除截图入口多余的 5000px 视口拉伸，由全文捕获函数负责需要的布局恢复。
- 真正的截图异常以 `BOSS_RESUME_CAPTURE_FAILED` 保留原因；不再伪装成空白内容，也不因此自动反复打开简历。
- 保持岗位规则、任务人数上限、查看计数与现有限额；仅处理原失败候选人。
