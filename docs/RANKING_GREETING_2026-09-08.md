# AI 排名一键打招呼（2026-09-08）

Release: `boss-ranking-greet-20260908-1705cst`。

在候选人「规则通过 · AI 排名」搜索栏加入一键打招呼入口。名单限定为当前岗位、当前任务和搜索结果，包含全部分页；打开时固定收件人范围，后来新增的候选人不会自动加入。

打开弹窗只读取 BOSS 当前岗位招呼语与模板，自动选中可联系人。支持重新读取、选择/修改快捷模板，并明确应用到 BOSS 岗位后再预览。没有模板也能使用 BOSS 已生效的招呼语。读取超时为 45 秒，对齐后台 40 秒 IPC 读取。

所选待审核候选人须由 HR 勾选确认后保存为人工通过，再生成真实发送预览。已淘汰、AI 低分未复核、AI 分析未完成及已有招呼记录的人会注明原因并跳过。已经人工复核通过的 AI 低分人选仍可联系。不会自动推翻人工淘汰或低分复核决定。

一次最多选择 200 人，每次 API 请求仍不超过 20 人，保持排名顺序。预览严格核对唯一候选人集合、岗位、任务、动作、消息正文；修改名单/间隔或正文后重新预览。真实发送继续校验已有签名、有效期、权限和联系控制。提交中途失败或部分成功即停止后续批次，记录已入队名单，刷新联系记录后只处理剩余人选。

后台依旧逐人间隔 60–600 秒执行；弹窗显示提交进度与已有队列进度，关闭后由原联系 Worker 继续处理。全局/部门联系开关保持原设置。

验证：107 个文件、739 项单元测试，类型检查、前端 lint 和 Linux amd64 生产构建通过。隔离浏览器测试覆盖 26 人跨页名单、23 人可联系、20＋3 分批、第二批失败后停止、余下 3 人重试不重复、异任务预览拒绝、修改选择使预览失效、搜索范围、375px/横屏/深色模式、Esc 和焦点恢复。所有 API 为测试替身，未向真实候选人发送消息。

生产更新前：5 岗位、69 候选人、4 任务、0 联系意图，BOSS 已登录且 Worker 就绪；全局与部门联系关闭且紧急停止启用。备份目录 `/opt/boss-forge/backups/ranking-greeting-20260908/`。不迁移数据库、不清理候选人或任务。

线上只读核对：AI 岗位 BOSS 专属招呼语为空（BOSS_GREETING_JOB_BODY_EMPTY），故原读取返回 greeting_unavailable。弹窗为此提供可编辑的建议参考消息；必须由用户明确应用到 BOSS 并读回成功，才进入发送预览。隔离浏览器已覆盖未配置、仅打开不修改、应用后更新参考内容。生产核对未更改 BOSS 招呼语、未发送消息。
