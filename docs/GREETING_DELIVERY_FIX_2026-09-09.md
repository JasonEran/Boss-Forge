## 修复

1. 当前聊天列表把加密 ID 放在原生 Vue 行模型 `geek/source.encryptUid/encryptFriendId`，原定位代码只读 DOM 属性和链接，造成候选人明明在聊天列表却找不到。增加模型读取，拒绝冲突 ID；打开后再次核对当前会话加密 ID。
2. 原生招呼只执行一次，随后只读打开准确聊天，核对数字 ID 与加密 ID 的映射、完整发出正文、服务端消息编号、成功状态和本次发送时间。空 greeting 或数字 ID 只有在实际消息证据满足时才可通过；缺失、旧消息、重复消息、他人会话、正文变化及明确阻断仍不判成功。
3. 发送路径关闭执行上下文销毁时整段回调自动重跑；只读路径原有恢复保留。取得完整回执后，非关键视口恢复或弹窗清理失败不覆盖发送成功。
