# 招呼语首次设置、Sol 主模型与简历滚动条修复

## 问题与修改

BOSS 当前亚马逊、AI 实习岗位的 `jobGreeting` / `encGreetingId` 为空；其余 3 个岗位有明确招呼语。原 CLI 将空配置报为 `BOSS_GREETING_JOB_BODY_EMPTY`，supervisor 又统一改成 `greeting_unavailable`，UI 用失败 Notice 展示并附带“相关数据没有更新”，把正常的首次设置当成技术故障。

现在通过 IPC 区分 `greeting_not_configured`，岗位 GET 返回 `configured:false, preview:null`，弹窗展示首次设置说明、可编辑参考消息及明确应用按钮。连接忙碌、登录失效、读取异常仍是单独的可操作错误；保留已输入草稿。打开弹窗不保存配置、不发送招呼。原生保存接口及 `encJobId/content` 参数已与 BOSS v11323 的官方前端代码核对。

AI 优先 `gpt-5.6-sol`，兜底 `gpt-5.6-luna`。只有请求、超时、JSON 或证据校验失败才切换；正常低分不重跑。评分记录实际使用的模型。评分、语义核验、同义词三条模型调用路径统一配置；Sol/Luna 使用 low reasoning 与 max_completion_tokens。主模型在配置了兜底时最多 90 秒，兜底保留原配置的 180 秒，最长 270 秒低于现有 5 分钟 AI claim 过期时间。历史评分保留。

参数依据：[GPT-5.6 Sol 官方文档](https://developers.openai.com/api/docs/models/gpt-5.6-sol)。中转站一次真实 Sol JSON 请求成功，返回模型 `gpt-5.6-sol`，约 72 秒；其余超时测试如实记录，不能将单次连通视为永久可用。

两份等待简历 ID：`48be95cb-5b83-4cfd-9cb4-d59d94045b74`、`6888772d-121b-4561-8218-95ddcb13337d`。现场几何读回：`.resume-detail-wrap` 外宽 582，clientWidth 578；iframe 内宽 578，而 canvas 保持 582，右侧 4 像素被滚动条占位裁切。原来的完整性检查正确拒绝保存并进入 5/10 分钟重试。修复在虚拟简历的所有截图/展开轮次前临时隐藏该容器滚动条，仍能原生滚动；所有轮次结束后恢复原样式，不放宽宽度、像素或页尾完整性要求。

## 后续 busy 修复及生产复验

应用参考消息的 POST 原来没有转换 IPC 错误；保存只等待账号锁 5 秒，简历精筛时返回英文 busy。现在 POST 返回明确的 busy 状态；弹窗仅对这种“尚未进入保存”的响应自动等待，最多 2 分钟，显示已等待时间；关闭页面取消后续重试。网络超时、保存未核实及登录失效不自动重复写入。保持参考消息与快捷模板内容。

同步生成同义词的前端等待时间与网关超时同步到 285/300 秒，覆盖主模型加兜底的最长 270 秒，避免网关默认 60 秒先中断。

110 文件 / 759 项测试、类型/lint、桌面/手机隔离 UI 验证通过。补充 IPC 验证忙碌时保存回调未执行；UI 验证 busy 时显示等待，空闲后只成功应用一次。线上两份指定记录均为 screened、error=null、完整截图 complete=true：第一份 582×1036，2 段；第二份 582×2196，4 段。OCR 分别为 63/118 行；均按现有 TEM-8 条件判 not_matched（读到 TEM-4），没有人为改变资格判定。其余 4 份既有异常未扩大重试范围。

Sol 的真实 JSON 请求成功；强制主模型 503 的兜底探针确认请求顺序为 Sol→Luna，但 Luna 当次 180 秒未返回，已如实记录失败，不能宣称中转站双模型均稳定可用。

最终发布：`boss-greet-sol-resume-20260908-1855cst`。发布和线上验证日志保存在同一备份目录。

真实完整评分探针随后成功：正常优先请求 Sol 后发生切换，Luna 在总计 139280ms 内完成虚构简历评分，88 分、3 个原文证据维度；请求顺序 Sol→Luna，结果实际模型 gpt-5.6-luna。该探针不保存候选人或评分数据、不触发采集/联系。先前独立探针超时记录保留。

最终线上验证：API 首次返回 409/busy，前端等待函数随后取得 200，原有正文和 greetingId 均一致。采用已有文案进行幂等读回，没有更换招呼语，也没有联系候选人。临时锁已释放，验证会话已撤销。HTTPS 健康检查、Web 与 Nginx 配置通过；本次上传包和几何诊断脚本已清理，备份及回退版本保留。
