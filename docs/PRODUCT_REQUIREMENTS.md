# Boss-Forge 产品需求

> 产品形态：内网 HR 招聘控制面
>
> 当前阶段：筛选、人工审核与 Fake 联系闭环

## 1. 产品目标

不同 HR 可以按岗位配置不同筛选条件，系统从 BOSS 推荐或搜索结果获取候选人，必要时预览完整简历并 OCR，给出可追溯的规则结论，最后由 HR 审核。

目标流程分两阶段：

1. 人工阶段：系统列出符合、歧义和信息不足的候选人，HR 核对证据后决定是否联系。
2. 自动阶段：人工阶段准确率稳定后，按岗位显式开启自动联系，并继续受全局熔断、限额、时段、冷却和幂等约束。

当前代码只完成第一阶段的数据与 Fake 联系闭环；第二阶段尚未开放。

## 2. 用户与权限

目标角色包括 HR、招聘负责人、面试官和管理员。不同 HR 应只查看被分配岗位的数据。

当前版本没有登录、用户表、部门表或服务端数据权限。API 中的 `createdBy`、`reviewerId` 和 `actorId` 由前端传入，Dashboard 使用固定操作者标识。因此当前版本只适合受控内网单团队试用，不能作为多部门权限验收通过的依据。

## 3. 岗位与规则

每个岗位至少包含：

- 岗位名称、BOSS 账号逻辑 ID、BOSS 岗位关键词和负责人名称。
- 一个当前生效规则版本；保存编辑会创建新版本，不覆盖旧版本。
- 推荐牛人或普通搜索两种筛选来源。

当前结构化规则表单支持：

- 根节点 AND 或 OR。
- TEM8 与最低置信度。
- BOSS 平台 `985`、`211`、`双一流`标签，支持任一或全部。
- 工作年限最小值/最大值。
- 最低学历。
- 技能关键词、地点和简历全文关键词，支持任一或全部。
- 缺失信息策略：人工复核、失败或忽略。

规则引擎还支持嵌套 AND/OR/NOT、通用文本/枚举和自定义院校目录，但 Dashboard 暂无任意嵌套可视化编辑器。

## 4. 语义归一化

TEM8 需要兼容 `TEM8`、`TEM-8`、`TEM 8`、`英语专业八级`、`专业英语八级`、`英语8级` 等常见表达，并区分：

- 已通过或已取得证书。
- 明确未通过。
- 备考、目标、课程要求或岗位要求。
- 与 CET-4/CET-6、TEM4、IELTS、TOEFL、BEC 等概念混淆。

候选人未达到 TEM8 时，页面应展示识别到的当前英语级别。

985/211/双一流只使用 BOSS 候选人卡片的显式平台标签，不从学校名称或简历自述推断，也不需要导入学校名单。

## 5. 执行方式

系统支持：

- 立即执行。
- 指定未来时间执行一次。
- 每天、工作日或每周周期执行。

定时计划到期后生成与立即执行相同的任务快照。搜索来源必须提供关键词。任务和计划创建请求必须携带幂等键。

## 6. 候选人与审核

系统按稳定指纹去重自然人，并按“候选人—岗位”保存独立状态。候选人详情应包含：

- BOSS 卡片原始字段和采集证据。
- 当前规则版本和规则结论。
- 简历预览/OCR 状态。
- TEM8 或当前英语级别。
- 每个规则叶子的证据、置信度和原因码。
- 审核历史和联系状态。

HR 可以审核通过或拒绝，提交备注和纠错类型。审核采用预期版本号防止并发覆盖。

## 7. 联系

当前产品流程是：审核通过 → 预览消息 → HR 创建联系意图 → Fake Worker 记录 `simulated`。

当前 Dashboard 联系意图固定 `transport_mode=fake`；API 返回 `realGreetingEnabled=false`。内网部署不包含 Real Worker。

产品级自动联系上线前必须补齐：

- 可操作的全局、岗位和任务开关。
- 权限与审批人。
- 权威的 BOSS 账号健康状态。
- 回复同步和 Do-Not-Contact 实时闭环。
- Real Worker 专项验收和紧急停止演练。

## 8. 页面范围

| 页面 | 当前职责 |
|---|---|
| 工作台 | 候选人数、规则通过、待审核、联系数和最新任务 |
| 岗位与规则 | 新建岗位、查看当前规则、编辑并创建新规则版本 |
| 任务与计划 | 立即执行、创建计划、查看任务和停用计划 |
| 候选人审核 | 按岗位查看待审核/已通过/已筛除，查看证据并审核 |
| 联系执行 | 预览消息、创建 Fake 联系意图、查看结果 |
| 审计与安全 | 查看关键动作和当前安全边界 |

## 9. 非功能要求

- 外部操作只能由 Worker 执行，浏览器不得直接调用 BOSS。
- 任务、审核、联系和计划必须幂等并保留审计。
- 已发布规则版本不可原地修改。
- 简历预览开关与联系开关必须独立。
- 单个候选人失败不能丢失已完成结果。
- 所有日期按 UTC 存储，计划业务时区当前固定为 `Asia/Shanghai`。
- 当前只部署在内网，不包含公网域名、TLS、CDN、WAF 或公网数据库方案。

## 10. 当前验收口径

当前阶段通过标准：

- 岗位、规则、立即任务和定时计划可以通过 Dashboard 创建。
- 推荐/搜索结果可去重入库并进入简历精筛队列。
- 规则证据、TEM8 和当前英语级别可查看。
- HR 审核、消息预览、Fake 联系和审计闭环可重复执行。
- 自动化测试与 E2E 明确断言没有真实打招呼。

多部门权限、招聘管道、面试、Offer、自动联系和分析不属于当前已通过范围。
