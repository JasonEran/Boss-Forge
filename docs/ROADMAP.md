# Boss-Forge R1–R6 交付记录

> 原则：借鉴成熟 ATS 业务模型，不引入第三方 ATS 运行时。
> 状态：release `audit-events-20260904-1614cst` 已生产部署；独立 greet/message、逐候选人短效签名预览许可和 Real Worker 失败关闭边界已上线。runtime real、全局/部门控制 safe-off，首次真实写入尚未验收；语义 active 继续关闭。

## R1：部门使用基础 — 已完成

- 用户、密码会话、四类角色、账号停用。
- 岗位负责人和协作者；服务端岗位级授权。
- 当前登录用户写入审计，不接受前端伪造操作者。
- 候选人服务端分页、岗位/阶段/姓名筛选、姓名/更新时间排序。
- E2E 验证两名 HR 数据隔离与跨岗位越权失败关闭。

## R2：招聘管道与协作 — 已完成

- 部门可配置阶段，默认覆盖筛选、审核、联系、沟通、面试、Offer、入职和淘汰。
- 时间线、备注、@协作者、附件元数据、跟进待办、面试参与人和反馈表。
- 面试官不能推进阶段，只能在获分配岗位提交反馈。
- 全局自然人身份、逐任务筛选/审核事实和分岗位当前视图；Do-Not-Contact 与淘汰原因。
- migration 023 与隔离 E2E 验证重复候选人在不同岗位、不同任务中保留独立结果，不再迁走历史状态。

## R3：规则运营 — 已完成

- 普通 HR 在岗位弹窗使用年龄、毕业年份、应届、性别、学历、CET-6/TEM-8 OR 等业务字段；后端保留嵌套 AND/OR/NOT 能力。
- 部门规则模板；Draft、Pending Approval、Published、Retired。
- 已发布配置由数据库触发器禁止原地修改。
- 固定历史简历双版本回放，保存变化清单；退役版本可回滚发布。
- 岗位弹窗由服务端一个事务创建并发布/送审规则；旧 `/rules`、`/semantic` 只保留兼容跳转。

## R4：通用语义筛选层 — 已完成控制面

- 部门级规范事实目录，覆盖任意证书、技能、职能、行业、项目和业务结果。
- 目录条目、提示词和模型名持久化版本；审批发布与回滚数据结构。
- HR 纠正写入固定评估集，不在线修改生产判断。
- 固定集计算样本数、准确率、精确率、召回率、未知率、纠错率和估算成本。
- 岗位只支持 off/shadow；`SEMANTIC_ACTIVE_DECISIONS_AVAILABLE=false`，migration 024 将存量 active 降为 shadow。
- 真实内网模型效果尚未验收；影子结果只用于观察，不进入规则通过/淘汰。

## R5：招聘运营与 BOSS 回复 — 控制面完成，远端数据源待复验

- BOSS 入站/出站消息的数据结构按外部消息 ID 幂等；人工注入只允许隔离 contact 测试，真实回复同步 Worker 尚未完成远端验收。
- 人才标签、跨岗位推荐、重复联系提示。
- 招聘漏斗、来源、审核、OCR 失败/无正文、未知判断和纠错指标。
- 账号健康、release、简历策略、只读 DOM 和 Worker 心跳可交叉展示；先前受控轮次已验证 `authenticated` 与新鲜心跳，单次 canary 已验证 `target_missing` 不重试。历史 `boundaryfix` 部署曾停止 worker 以保护排队简历；当前 release 已恢复 authenticated supervisor。风控和其他真实失败样本仍待自然复验。
- 部门 JSON/CSV 导出任务与数据保留策略。

## R6：联系安全控制 — 已部署，待首次 canary

- 全局、部门、岗位、任务四级控制记录、状态展示与审计。
- 每日/每小时额度、时段、冷却、四级开关和紧急停止共同失败关闭；普通 HR 不需要理解额外审批流。
- 权威账号健康、Do-Not-Contact、开关、审批和紧急停止共同决定就绪状态。
- 关闭任一级或 DNC 均失败关闭；Fake 状态机只允许在显式隔离测试中运行。
- greet/message 已拆分为独立预览、短效签名许可、意图、动作级去重和回执；正文发送不隐式打招呼。
- Real Worker 仅通过 authenticated supervisor 的私有 IPC 复用现有浏览器；全局 fence、账号锁和最终重验保证一次许可最多一次对应外部写，未知结果不自动重试。
- 编译能力和生产 real runtime 已开启，但全局/部门控制 safe-off，联系队列、intent、attempt、authorization 均为 0。当前没有符合条件且已审核通过的候选人，首次 canary 仍等待用户对具体动作、候选人、BOSS 发件账号和完整正文的精确许可。
