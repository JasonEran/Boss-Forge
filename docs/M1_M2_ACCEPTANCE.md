## 4. HR 用户流程 E2E

`pnpm test:e2e:user` 使用合成数据，并通过与 Dashboard 相同的 HTTP/API 路径执行：

1. 创建岗位。
2. 创建 TEM8 规则版本。
3. 创建立即筛选任务。
4. 写入一名带 TEM8 原文证据的合成候选人。
5. 使用合成 OCR 结果完成完整简历精筛并查看识别等级。
6. 查看候选人详情并人工审核通过。
7. 生成消息预览。
8. 显式确认并创建 `ready` 联系意图。
9. 创建并停用工作日定时计划。
10. 验证候选人状态、联系记录和审计日志。
11. 删除全部合成岗位、任务、候选人、联系意图和审计数据。

测试结果必须包含：

```json
{
  "ok": true,
  "realGreetingExecuted": false
}
```

1. M3 人工试运行指标达到业务负责人设定的阈值。

6. 验收结束立即恢复 `BOSS_FORGE_REAL_GREET_ENABLED=0`。
