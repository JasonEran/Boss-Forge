# 毕业年份识别修复 · 2026-09-11

已发布 `boss-graduation-fix-20260911-2040cst`。用户反馈江梦已经毕业却被筛掉；核查发现已保存简历明确包含「安徽农业大学商务英语本科，2021–2025」，英语专八证据也为正面，但毕业年份被误解析为缺失，触发岗位既有的缺失信息不通过规则。

## 原因与修复

学历解析器结束一条教育记录后，仍会把「在校经历」正文中的「我在学校……」「大学生职业生涯发展中心」或「外国语学院」当作新学校。新学校没有有效学历时间，导致整份简历的毕业年份作废。「QS 世界大学排名」也会被误当成学校条目。

现在明确区分学历表头与校园经历、论文和描述正文，院校排名标签不再创建学校记录。描述后出现新的学历时，必须具有独立学历信息才能开始新记录。教育经历中的「至今／在读／未毕业」继续作为未完成学业的证据；校园经历标题及「在读期间」不再单独代表当前在读。

本次只修复解析及其证据使用，没有放宽线上岗位的毕业年份上限或缺失信息处理策略。本机原有、尚未上线的两处“毕业信息缺失默认放行”逻辑未随本次部署；发布文件哈希以验收目录中的 `release-source-manifest.json` 为准。
