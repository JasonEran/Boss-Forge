# boss-cli 集成边界

> 锁定包：`@joohw/boss-cli@0.6.6`。以 pnpm 锁文件与仓库补丁为准，不自动追随上游最新版。

## 1. 谁负责什么

| 层 | 责任 |
| --- | --- |
| 上游 boss-cli | 提供会话、推荐/搜索读取、简历预览、聊天等基础模块 |
| [本地补丁](../patches/@joohw__boss-cli@0.6.6.patch) | 修正本项目需要的浏览器连接、完整简历、身份/正文绑定、动作回执及重试边界 |
| `packages/boss-cli-adapter` | 版本校验、类型化命令、输出解析、账号锁、私有 IPC 和风险分类 |
| `apps/boss-worker` | supervisor、扫码、岗位/VIP筛选、候选人定位、沟通及执行协调 |
| 数据层 / API | 规则与任务身份、权限、幂等、队列、控制、审核和审计 |

项目已包含自有 DOM 适配和登录编排，旧文档中“不维护任何选择器”“补丁只增加标签行”的描述已不成立。原则是复用上游基础模块，必要适配集中维护并有明确契约，不另外启动独立会话或无锁抓取器。

## 2. 能力使用方式

- 岗位同步读取当前官方职位管理页面，按可验证岗位 ID 保存；推荐读取按绑定 ID 选择岗位。
- 推荐和搜索复用上游读取/渲染能力，自有逻辑处理岗位、官方筛选、分波与候选人来源。
- 简历预览检查身份和截图完整性；需要时提交已批准的 OCR 提供方。
- 真实 greet/message 经产品预览或已授权任务策略、联系 Worker、私有 IPC 与发送前重验，不能把 CLI 支持理解为可直接发送。
- 实时沟通和原生动作有自己的会话、消息身份与回执绑定。
- M0 只用于受控诊断，不能绕开产品联系检查；安装命令的支持范围不等于 UI 全部开放范围。

## 3. 补丁范围

`pnpm-workspace.yaml` 的 `patchedDependencies` 将补丁应用到 0.6.6。当前补丁涵盖：

- CDP remote-only 与浏览器生命周期约束。
- 推荐文本标签和候选人稳定来源。
- 简历 iframe 等待、完整截图、OCR 路径和页面清理。
- greet 预览与精确岗位/招呼语/正文校验。
- chat/send 的候选人目标、请求/回执与不重复执行边界。
- 会话重试策略和官方页面保护。

以上按补丁的实际文件范围归纳，具体变动以补丁 diff 为准。上游升级不能只改 package 版本而漏掉这些行为。

## 4. 风险与并发

| 操作 | 约束 |
| --- | --- |
| 状态 / 列表读取 | 有登录态、账号锁和频率要求；不随意导航正在使用的浏览器 |
| 简历查看 / OCR | 会触发真实平台访问，可能消耗额度；与联系开关独立 |
| greet / send / 原生申请 | 外部动作，必须经过已授权的产品流程和回执核验 |

同账号所有操作串行；任务只能由对应账号 Worker 领取。姓名相同不足以确定目标，要核对岗位与稳定 locator。找不到原候选人、目标歧义或来源已变化时停止该动作，不改看/改联系另一个人。

只读 CDP 调试使用 `defaultViewport: null` 并在结束时 disconnect，不能关闭生产浏览器。浏览器资料和 `.boss-cli` 不进 Git、不跨操作系统复制。

## 5. 升级验收

1. 对照上游变更和当前补丁逐项确认，决定重放、替换或删除哪些补丁。
2. 更新版本允许列表、锁文件及脱敏解析 fixture；未知版本失败关闭。
3. 运行适配器、岗位/VIP选项、简历完整性、扫码和联系回执回归。
4. 隔离 Chrome 验证上下文销毁/iframe更换/慢响应，证明外部写不会被自动重复执行。
5. 在目标 Linux 运行环境完成类型、构建和启动检查，记录浏览器版本。
6. 现场先只读核对，真实业务动作仅在明确授权范围内进行。

不实现验证码、风控或额度绕过；不从学校名称或模型猜测 BOSS 平台院校标签。上游源码为第三方依赖，按[验证指南](TESTING.md)记录实际覆盖，不能把版本号一致当作行为完全兼容。
