# 前端切换与后台进度优化 · 2026-09-05

发布版本：`frontend-perf-20260905-1748cst`。

## 改动

- 新手导览此前通过整页导航跨页，每次重新检查登录并加载数据。现在已登录工作区在站内保持，13 个实际页面按需加载，导览提前加载下一步所需页面与数据；加载期间保留当前内容，提供页顶进度和失败重试。
- 保留真实链接、刷新直达、浏览器前进后退及新标签打开。采用现有客户端组件切换，避免再次依赖此前出现 Safari 问题的 RSC 导航。
- 登录、工作台数据及导览状态由共享上下文管理。工作台每 5 秒同步一次，隐藏页面暂停轮询；同一账号的并发读取合并，短期数据用于返回页面时先显示内容，再获取最新数据。写入成功和退出登录会清除缓存。
- 页头增加“后台进度”：筛选任务、联系动作、上次同步时间、后台与 BOSS 连接情况。任务详情、任务列表及候选人名单增加真实处理数量、进度条和进度圈，区分待处理、处理中、精筛完成与异常。
- 数量尚未确定时使用不定进度；100% 代表已处理数量，不代表全部通过。后台状态读取现有运行状态文件，不触发候选人采集或联系。
- 页面加载和 API 请求增加有界等待及可读错误，避免无限转圈。数据库结构与依赖版本未变。

## 验证
