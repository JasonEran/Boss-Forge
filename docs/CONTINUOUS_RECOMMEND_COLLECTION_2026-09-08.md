# 按人数持续加载 BOSS 推荐

日期：2026-09-08。已发布版本：`boss-continuous-recommend-20260908-1540cst`。

## 行为

新建推荐筛选任务时，将已保存的本次人数上限传入岗位浏览器采集。固定 BOSS 岗位和官方筛选条件后，先读取当前已加载的符合候选人；人数不足且 BOSS 仍有更多符合推荐时，通过页面滚动触发下一页，核对成功响应、岗位 ID、分页号及实际渲染完成，再继续采集。

- 按 BOSS 候选人 ID 去重，保留同名的不同候选人；达到 1–200 的任务上限立即截断，数据库人数上限校验继续生效。
- 遇到官方补充推荐分隔线或原生 finished/hasMore 结束状态，停止继续加载。短页、重复页、滚动未变化和接口超时本身都不算“耗尽”。连续无新增、分页异常或网络错误会明确失败，不伪造采集完成。
- 每次下一页加载之间至少间隔 1 秒；只使用 BOSS 原生滚动，不调用隐藏业务方法或直接请求候选人接口。
- 只有新任务采集路径启用持续加载。简历恢复上下文、实时选项读取和岗位同步继续沿用原读取路径，避免每次精筛重新全量采集。
- 每轮采集核对任务状态和 claim token；任务取消或领取归属变化后停止后续加载及结果交付。采集子命令超时为 5 分钟，其他岗位/选项命令仍为 90 秒。
- 已经进入精筛的旧任务不重新补采，也不更改其冻结规则。
