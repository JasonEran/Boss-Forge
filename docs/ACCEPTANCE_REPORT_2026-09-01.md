管理员策略恢复后，应补跑以下路径：

1. 使用默认管理员或实际管理员登录，确认会话和退出登录。
2. 新建岗位并分配 HR，确认无权用户看不到岗位数据。
3. 打开候选人管道，验证筛选、阶段推进、备注、待办、面试和 DNC。
4. 创建 AND/OR/NOT 规则草稿，提交审批、发布并执行历史回放。
5. 检查语义目录、评估指标和低于 90% 时 active 失败关闭。
6. 检查运营指标、标签、回复、健康告警和导出入口。
7. 检查四级自动化开关、审批、紧急停止和 Fake-only 提示；不得执行真实打招呼。
8. 检查桌面与窄屏布局，并确认浏览器控制台无未处理错误。

## 6. 风险与上线建议

- 在浏览器可视验收补齐前，建议只作为内网试用版本，不宣布 UI 验收完全通过。
- 首次试用前修改默认管理员密码并创建实际 HR 成员账号。
- 语义模型保持 `off` 或 `shadow`，直到真实岗位金标集达到准入指标。
