## 筛选结论修正

- 简历只有 CET6、雅思或其他证书，不再据此断言候选人没有 TEM8。明确取得、明确否定和证据缺失分别处理；存在冲突或计划考证不会算取得。
- 英语条件“任一/全部”正确区分否定和未知；确认 TEM8 必须有对应证据。历史性别条件不参与自动通过或淘汰。
- 候选人列表、详情、看板分别显示读取未完成、等待精筛、正在精筛、规则通过、规则不符、证据有歧义、证据待补充。未完成精筛不会显示成规则通过。
- 修复看板数据缺少精筛状态/错误码，以及缺失条件混入不符合条件的问题。
- 岗位读取浏览器回调改为可独立执行脚本，避免 tsx 转译的 `__name` helper 在浏览器丢失。连接检查限制超时；连接不可用时 supervisor 暂停浏览器任务，恢复后再继续。调度异常不会再挡住即时任务或已采集简历处理。

## 新增官方筛选流程

1. HR 同步、选择现有 BOSS 岗位，在岗位规则中设置“第一步 · BOSS 官方筛选”。
2. 默认自动对应必须满足的学历、工作经验条件；“本科及以上”映射为本科、硕士、博士，“高中/中专及以上”包含中专/中技。工作经验按有交集的官方区间宽筛，精确年数留到简历核验；包含在校/应届的范围暂留本地，避免 BOSS 联动排斥。
3. OR、NOT、允许未知的条件不会自动收窄整个候选池。自定义模式支持学历、经验、院校、专业、牛人关键词、活跃度和近 14 天未看过；不设置年龄、性别等个人属性的官方筛选。
4. Worker 先按 BOSS 岗位 ID 切换推荐，再通过界面清除遗留条件、选择目标选项、确认并重新检查保存状态。缺少选项、VIP 不支持、联动冲突或未保存时明确失败，不静默采集错误候选池。
5. 采集完成时把已验证的条件保存到 `tasks.source_boss_filters`。精筛恢复使用采集时的条件，后续修改规则不会改变原任务上下文。历史任务 NULL 不补套新筛选。
6. 同岗位、同已生效条件只收起面板，不再次确认刷新推荐，减少候选人定位过期。岗位下拉新增读取实际 `value` 属性和 `.curr` 当前项。
7. 前端任务进度显示已应用的官方条件。证书等官方未提供的条件继续在完整简历中核验。

规则保存于原有版本快照；新增 migration `029_boss_recommendation_filters.sql`，只有一个可空 jsonb 列，无删除性迁移。

## 登录持久化跟进

2026-09-07 检查发现服务器原有 `wt2`、`zp_at` 登录 Cookie 和浏览器资料仍存在于原持久化卷，Cookie 标注的到期日在检查时间之后；但正常进入招聘页后，BOSS 跳回 `/web/user/?ka=bticket`。这说明当前凭证未能恢复访问，不能把本地未到期等同于服务端仍认可。Safari 仍登录，但 macOS 拒绝读取其 Cookie 文件；用户随后决定使用服务器扫码，不再尝试迁移 Safari 会话。

后续版本 `login-persist-20260907-1540cst` 补充启动时的会话恢复：优先沿用现有招聘页；存在 BOSS 登录 Cookie 时先正常进入招聘页并等待加载完成，再由页面登录信号判断；需要登录才显示二维码。不会仅凭 Cookie 存在启动 Worker。保持相同外部浏览器数据卷和 Default profile，浏览器运行环境沿用前版。95 个测试文件、631 项测试在本机和 Linux amd64 镜像内通过，类型检查通过；无数据库迁移、未更改前端构建。

持久化用于保留部署和重启前的本地登录资料，不能阻止 BOSS 撤销或过期凭证。真实“扫码成功 → 重启 → 仍已登录”验收必须在新扫码成功后进行，尚未以已失效的旧凭证宣称通过。

后续真实验收已完成：用户扫码后，2026-09-07 15:44 CST 检查为 authenticated，Worker ready、心跳新鲜，队列空闲；受控重启 boss-login 后 15:45 CST 自动恢复 authenticated，浏览器及 Worker 两项校验为 true，全程无需再次扫码。证据保存于上述登录版本备份目录的 `restart-before.json`、`restart-after.json`。

## 新版职位页读取验收

登录恢复后实际读取发现 BOSS 账号使用 `/web/frame/job_v2/list`：原 `.job-jobInfo-warp` 选择器取不到可见的 12 个岗位。当前版本补充 `.job-item-container`、`.job-title .job-name`；从页面已渲染的 Vue 3 卡片 `jobInfo.encryptJobId/encryptId` 获取对应 ID，保留旧版 DOM 兼容。只读取渲染数据，不调用 BOSS 私有方法或编辑岗位。同时修复总数先出现、卡片尚未加载时过早结束读取的问题，翻页按实际读取的 ID 判断是否切换。

真实页面读到 12 个不同 ID：5 个开放中、4 个待开放、3 个已关闭；包含同名“亚马逊运营”不同岗位。新增真实 tsx 序列化回归覆盖同名岗位映射、循环渲染节点、加载中与真实空列表。95 个文件、633 项测试在本机和 Linux amd64 通过，类型检查通过，无新增数据库迁移。随后部署当前版本，镜像更新重建容器后仍自动恢复原会话，API/浏览器/Worker 版本及状态一致。发布与验证日志在 `/opt/boss-forge/backups/job-v2-20260907-1550cst/`。本次没有创建筛选任务或执行候选人联系。
